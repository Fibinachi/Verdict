Getting Started

What is Verdict?

Verdict is a courtroom simulation and case management application for Windows. It provides a visual courtroom environment where you can manage cases, assign agents (judge, jurors, attorneys, witnesses), submit evidence, and simulate trial proceedings with AI-powered analysis and interactions.

Built with .NET 9 and WPF (Windows Presentation Foundation), Verdict follows the MVVM (Model-View-ViewModel) architectural pattern for clean separation of concerns.

System Requirements

  • Operating System: Windows 10 or later (native Windows deployment only)
  • .NET Runtime: .NET 9 SDK or runtime installed
  • RAM: 4 GB minimum (8 GB recommended for LLM interactions)
  • Storage: 100 MB for the application, plus space for case files and evidence

Building and Running

Open a terminal (PowerShell recommended) in the project root directory and use the following commands:

Build the application

dotnet build

Run the application

dotnet run

Run tests

dotnet run --project Tests/Tests.csproj

Clean build artifacts

dotnet clean
Note: The preferred shell for development is PowerShell. All commands should work in both PowerShell and Command Prompt.

Main Window Overview

When you launch Verdict, you are presented with the main courtroom window. The layout includes:

  • Menu Bar at the top with File, Case, Stage, Settings, and Help menus.
  • Bench Area at the front with seats for Judge, Reporter, and Witness.
  • Counsel Tables on the left (Defense) and right (Prosecution/Plaintiff).
  • Jury Box with 12 primary seats and 2 alternate seats.
  • Observer Box with up to 6 seats for gallery observation.
  • Clerk Seat (highlighted in green) for evidence submission via drag-and-drop.
  • Input Prompt at the bottom with a central Podium button for focus.
  • Dynamic Title Bar that displays the case name and current stage.
