Juror Report

The Juror Report provides a detailed analysis of any juror or alternate juror in the jury box. It displays demographics, sentiment analysis, verdict lean, bias indicators, and memory history.

Opening a Juror Report

  1. Right-click on any juror or alternate seat in the jury box.
  2. Select Juror Report from the context menu.
  3. The JurorReportWindow opens with detailed information about that juror.

Report Sections

Demographics

Displays the juror's demographic profile including age, gender, occupation, education level, income bracket, and geographic region. These demographics influence the juror's biases and decision-making patterns.

Sentiment

Shows the juror's current sentiment toward the case, measured as a percentage from 0% to 100%. Sentiment reflects the juror's overall attitude and is influenced by evidence presented, arguments heard, and the juror's inherent biases.

72% Positive

Verdict Lean

Indicates the juror's tendency toward one side, displayed as a percentage:

  • 0% — Strongly favors the Defense
  • 50% — Neutral / Undecided
  • 100% — Strongly favors the Plaintiff/Prosecution
65% Plaintiff

Bias

A numerical bias score ranging from -1.0 to +1.0:

  • Negative values — Bias toward the Defense
  • Positive values — Bias toward the Plaintiff/Prosecution
  • Zero — Neutral / No bias

Trial Memories Tab

Lists memories created during the trial process, such as evidence presentations, witness testimony, and attorney arguments. These are tagged with Source = "TrialEvent" and directly influence the juror's evolving opinion.

Background Memories Tab

Shows the juror's pre-existing memories and background information that shape their worldview and biases. These are set when the juror is created or configured.

Colored Strength Bars

Each memory is displayed with a colored strength bar indicating how strongly that memory influences the juror:

  • Green — Strong influence
  • Yellow — Moderate influence
  • Red — Weak influence
Tip: Use the Juror Report to understand how each juror is likely to vote. This can help you tailor your arguments and evidence presentation to sway undecided jurors.
