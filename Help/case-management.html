Case Management

File Menu Overview

The File menu provides all case-level operations including creating, opening, saving, and managing recent cases.

New Case

Select File > New Case to create a new case. You will be prompted to enter:

  • Case Name — A descriptive title for the case (e.g., "Smith v. Johnson").
  • Plaintiff/Prosecution — The party bringing the case.
  • Defendant — The party being accused or sued.
  • Case Type — Criminal or Civil.

Once created, the case name appears in the window title bar and a corresponding .jur file is created when saved.

Open Case

Select File > Open Case to load an existing case from a .jur file. These files contain the full simulation state including agent configurations, evidence, memories, and trial phase information.

When a case is loaded, the courtroom layout is populated with the saved agents and the title bar updates to reflect the case name and current stage.

Save / Save As

  • File > Save — Saves the current case to its associated .jur file. If the case has not been saved before, this behaves like Save As.
  • File > Save As — Saves the current case to a new .jur file, allowing you to create a copy or save to a different location.

When you save a case, a sibling directory named [CaseName]_Assets/ is created alongside the .jur file to store evidence documents and agent artifacts.

Recent Files

The File > Recent Files submenu lists recently opened .jur files for quick access. Click any entry to load that case directly.

Case Settings

Select File > Case Settings (or use the Case Settings button) to open the CaseSettingsWindow. Here you can configure:

  • Case Name — Edit the case title.
  • Plaintiff / Defendant — Update party names.
  • Jurisdiction — Set the jurisdiction type.
  • Case Mode — Switch between Criminal and Civil modes.
  • Jury Instructions — Configure instructions for the jury.
Tip: Case files use the .jur extension and are stored as JSON. You can back up or share case files by copying the .jur file and its associated _Assets folder.
