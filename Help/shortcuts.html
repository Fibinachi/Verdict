Shortcuts & Interactions

This page summarizes all the interactive elements and shortcuts available in the Verdict courtroom interface.

Right-Click Context Menus

Right-click on any occupied agent seat to open a context menu with the following options:

  • Edit Profile — Opens the Agent Profile window to modify the agent's settings.
  • Generate Likely Juror — (Juror seats) Automatically generates a juror with demographic data.
  • Chat — Opens the Agent Chat window for LLM-powered conversation.
  • Juror Report — (Juror/Alternate seats) Opens the Juror Report with sentiment and verdict analysis.
  • Save as Character .VCS — Saves the agent as a reusable character profile file.
  • Save to Casefile — Saves the agent's current state to the case file.
  • Delete — Removes the agent from the seat.

Left-Click "+" (Add Agent)

Click the "+" button on any empty seat to add a new agent. This opens the Agent Profile window where you can configure the agent's name, role, prompt, and model settings.

Podium Button

The central Podium button at the bottom of the courtroom focuses the input prompt. Click it to quickly access the text input area for entering commands or messages.

Stage Menu

The Stage menu (located between File and Case in the menu bar) provides trial phase and court phase controls:

  • Trial Phases: Discovery, Pretrial, Trial
  • Court Phases: Opening Statements, Witness Testimony, Cross Examination, Party Statements, Closing Arguments, Jury Deliberation

Generate Jury Button

The Generate Jury button populates all empty jury box seats with demographically-generated jurors. Each juror receives a unique profile with age, gender, occupation, education, income, region, and associated biases.

Clerk Seat (Evidence Submission)

The Clerk Seat (highlighted in green) accepts drag-and-drop file submissions for evidence. You can also use the ADMIT EVIDENCE button to open a file dialog.

Case Menu

The Case menu provides access to:

  • _Exhibit List — Opens the Exhibit List window showing all evidence.

File Menu

The File menu provides:

  • New Case, Open Case, Save, Save As, Recent Files, Case Settings.

Settings Menu

The Settings menu provides access to Model Settings for configuring LLM providers and models.

Tip: Most interactions in Verdict are mouse-driven. The right-click context menu is the primary way to access agent-specific features.
