Agents Overview

Agents are the characters that populate your courtroom. Each agent has a role (Judge, Juror, Attorney, Witness, etc.), a profile with prompts and memories, and can be assigned to a specific seat in the courtroom layout.

Research context (citations)

Verdict’s multi-agent deliberation and jury-diversity concepts are inspired by the following works:

  • Devadiga, P., Shetty, O. J., & Agarwal, P. (2025). SAMVAD: A Multi-Agent System for Simulating Judicial Deliberation Dynamics in India. arXiv:2509.03793.
  • Grim, P., et al. (2024). The Epistemic Role of Diversity in Juries: An Agent-Based Model. JASSS 27(1), 12.
  • Jiang, C., & Yang, X. (2024). Agents on the Bench: Large Language Model Based Multi Agent Framework for Trustworthy Digital Justice. arXiv:2412.18697.
  • Anonymous (2026). 12 Angry AI Agents: Evaluating Multi-Agent LLM Decision-Making Through Cinematic Jury Deliberation. arXiv:2605.01986.

These citations describe the general modeling inspiration; specific quantitative parameters in the app are implemented in code.

Adding Agents

To add an agent to an empty seat:

  1. Click the "+" button on any empty seat in the courtroom.
  2. The Agent Profile Window opens, allowing you to configure the agent's details.
  3. Fill in the agent's name, role, and other profile information.
  4. Click Save to place the agent in the seat.

Editing Agent Profiles

To edit an existing agent:

  1. Right-click on the agent's seat.
  2. Select Edit Profile from the context menu.
  3. The Agent Profile Window opens with the current settings pre-filled.
  4. Modify the agent's name, prompt, memories, or settings as needed.
  5. Click Save to apply changes.

Saving Characters (.VCS Files)

You can save any agent as a reusable character profile:

  1. Right-click on the agent's seat.
  2. Select Save as Character .VCS from the context menu.
  3. The agent's profile (prompts, memories, settings) is saved as a .vcs (Verdict Character Settings) file in the /Characters repository.
  4. Saved characters can be loaded later to quickly populate seats with pre-configured agents.

Deleting Agents

To remove an agent from a seat:

  1. Right-click on the agent's seat.
  2. Select Delete from the context menu.
  3. The agent is removed from the seat. Note that this does not delete saved character files.

Other Context Menu Options

  • Chat — Opens the Agent Chat window for LLM-powered conversation with the agent (conversation memory is persisted, and there is a "Wipe Memories" action). (Experimental feature)
  • Juror Report — (Juror seats only) Opens the Juror Report window showing sentiment, verdict lean, and a memory summary. (Experimental feature)
  • Generate Likely Juror — (Juror seats only) Generates a juror profile with demographic data (including knowledge-domain defaults). (Experimental feature)
  • Save to Casefile — Persists the agent's current state into the case file (.jur).

Agent Roles

Available agent roles include: Judge, Juror, Attorney (Prosecution/Plaintiff), Attorney (Defense), Witness, Court Reporter, Clerk, Observer, and Client. Each role has specific behaviors and interactions within the simulation.
