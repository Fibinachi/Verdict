Evidence Management

Evidence is a core component of any case. Verdict supports submitting documents, images, videos, and audio files as evidence, with AI-powered analysis to extract insights, assess strength, and calculate probative value.

Submitting Evidence

There are two ways to submit evidence:

Method 1: Clerk Seat (Drag and Drop)

  1. Locate the Clerk Seat (highlighted in green) in the courtroom.
  2. Drag a supported file from Windows File Explorer onto the clerk seat.
  3. The file is automatically processed and added as evidence.

Method 2: ADMIT EVIDENCE Button

  1. Click the ADMIT EVIDENCE button in the courtroom interface.
  2. A file dialog opens allowing you to browse and select a file.
  3. Select the file and click Open to submit it as evidence.

Supported File Types

Verdict supports the following file formats for evidence submission:

.PDF .TXT .DOCX .RTF .JPG .JPEG .PNG .GIF .BMP .MP4 .MOV .AVI .WMV .MKV .MP3 .WAV .OGG

Media Type Classification

When evidence is submitted, Verdict automatically classifies it into one of four media types:

  • "Document" — For text-based files: PDF, TXT, DOCX, RTF.
  • "Image" — For image files: JPG, JPEG, PNG, GIF, BMP, WEBP.
  • "Video" — For video files: MP4, MOV, AVI, WMV, MKV, WEBM.
  • "Audio" — For audio files: MP3, WAV, OGG, WMA, M4A, FLAC.

This classification is stored in the MediaType property and is used for display and reporting.

Evidence Category & Probative Weighting

Beyond simple media type, Verdict assigns each piece of evidence an Evidence Category that determines its probative weight in the simulation:

  • "Document" — Written documents: contracts, reports, correspondence. Baseline impact (1.0×).
  • "Image" — Photographs and images. Higher impact (1.4×) — visual evidence is compelling.
  • "Video" — Video recordings. Highest impact (1.6×) — seeing is believing.
  • "Audio" — Audio recordings. Moderate-high impact (1.3×) — hearing a voice adds authenticity.
  • "Physical" — Physical/tangible evidence: weapons, DNA, fingerprints. High impact (1.5×).
  • "Testimony" — Witness statements, depositions, affidavits. Base impact (1.0×) scaled by witness credibility.

Verdict automatically determines the category from the file type and content analysis. Testimony is detected by keywords like "witness statement," "deposition," or "affidavit."

Probative Value vs. Evidence Strength

Verdict distinguishes two separate metrics for each piece of evidence:

  • Evidence Strength (EvidenceStrength) — The raw persuasive impact of the evidence. Influenced by media type (videos and images have higher impact), keyword analysis, and legal multipliers. Displayed as a percentage in the exhibit list.
  • Probative Value (ProbativeValue) — The legal weight of the evidence. Accounts for reliability (chain of custody), direct vs. circumstantial nature, hearsay concerns, and witness credibility. This is the value used by jurors when updating their verdict lean.
Key distinction: A graphic video may have high impact (Evidence Strength) but limited legal weight (Probative Value) if it's unreliable or hearsay. Conversely, a dry contract may have low impact but high probative value if it's authenticated and directly relevant.

Witness Credibility

For testimonial evidence (witness statements, depositions, affidavits), Verdict assesses Witness Credibility (WitnessCredibility) on a 0.0–1.0 scale:

  • Expert witnesses (forensic experts, medical examiners) start at 0.85 credibility.
  • Eyewitnesses start at 0.60 (eyewitness testimony is notoriously unreliable in real trials).
  • Law enforcement witnesses start at 0.75 credibility.
  • Character witnesses start at 0.45 credibility.
  • Red flags like inconsistent statements, prior convictions, or bias allegations reduce credibility.

Critical: Each juror then assesses credibility through their own biases — a juror's age, education, political affiliation, and current attentiveness all affect how credible they find a given witness. See Juror Credibility Assessment for details.

Reliability Score

Each piece of evidence has a Reliability Score (ReliabilityScore, default 0.8) that reflects chain of custody and authenticity. This score directly scales the probative value. Evidence flagged as unauthenticated or unverified receives a lower reliability score, reducing its probative weight.

AI Analysis

When evidence is submitted, Verdict performs an AI-powered analysis that includes:

  • Summary — A concise summary of the evidence content.
  • Key Points — Important facts and details extracted from the evidence.
  • Relevance Assessment — How relevant the evidence is to the current case.
  • Evidence Category — Automatic classification (Document, Image, Video, Audio, Physical, Testimony).
  • Evidence Strength — Raw persuasive impact, weighted by media type.
  • Probative Value — Legal weight after reliability, hearsay, and credibility assessment.
  • Witness Credibility — For testimony, the assessed credibility of the witness.
  • Detailed Analysis — A comprehensive analysis stored in the DetailedAnalysis field for full LLM analysis storage.
  • Damages Estimation — Parsed dollar amounts and legal multipliers (treble damages, punitive multipliers).
Note: The AI analysis uses the configured LLM provider and model. Ensure your model settings are properly configured for the best analysis results.

Evidence Storage

When evidence is submitted, the file is copied to the case's _Assets directory (e.g., MyCase_Assets/) for organized storage alongside the case file.
