Evidence Management

Evidence is a core component of any case. Verdict supports submitting documents and images as evidence, with AI-powered analysis to extract insights and assess strength.

Submitting Evidence

There are two ways to submit evidence:

Method 1: Clerk Seat (Drag and Drop)

  1. Locate the Clerk Seat (highlighted in green) in the courtroom.
  2. Drag a supported file from Windows File Explorer onto the clerk seat.
  3. The file is automatically processed and added as evidence.

Method 2: ADMIT EVIDENCE Button

  1. Click the ADMIT EVIDENCE button in the courtroom interface.
  2. A file dialog opens allowing you to browse and select a file.
  3. Select the file and click Open to submit it as evidence.

Supported File Types

Verdict supports the following file formats for evidence submission:

.PDF .TXT .DOCX .RTF .JPG .JPEG .PNG .GIF .BMP

Media Type Classification

When evidence is submitted, Verdict automatically classifies it into one of two media types:

  • "Document" — For text-based files: PDF, TXT, DOCX, RTF.
  • "Image" — For image files: JPG, JPEG, PNG, GIF, BMP.

This classification is stored in the MediaType property of the EvidenceDocument object and affects how the evidence is analyzed and displayed.

AI Analysis

When evidence is submitted, Verdict performs an AI-powered analysis that includes:

  • Summary — A concise summary of the evidence content.
  • Key Points — Important facts and details extracted from the evidence.
  • Relevance Assessment — How relevant the evidence is to the current case.
  • Strength Rating — An assessment of how strong or compelling the evidence is.
  • Detailed Analysis — A comprehensive analysis stored in the DetailedAnalysis field of the EvidenceDocument for full LLM analysis storage.
Note: The AI analysis uses the configured LLM provider and model. Ensure your model settings are properly configured for the best analysis results.

Evidence Storage

When evidence is submitted, the file is copied to the case's _Assets directory (e.g., MyCase_Assets/) for organized storage alongside the case file.
