Agent Chat

The Agent Chat feature allows you to have LLM-powered conversations with any agent in the courtroom. This is useful for questioning witnesses, discussing strategy with attorneys, or exploring a juror's perspective on the case.

Opening Agent Chat

  1. Right-click on any occupied agent seat in the courtroom.
  2. Select Chat from the context menu.
  3. The AgentChatWindow opens, displaying a conversation interface.

How It Works

When you send a message in the chat window:

  • The message is sent to the LLM (Language Model) configured for that specific agent.
  • The agent responds using its assigned model and provider (e.g., OpenAI, Anthropic, Google Gemini, Ollama).
  • The agent's profile prompt and memories are included as context for the conversation.
  • The response is displayed in the chat window.

Memory Persistence

Chat conversations are automatically saved as memories:

  • Each chat message is stored as a MemoryEntry object.
  • Memories are tagged with Source = "Chat" to distinguish them from other types of memories (e.g., trial events, background).
  • These memories persist across sessions and are saved in the case file.
  • When you chat with an agent again later, it can recall previous conversations.

Managing Chat Memories

The chat window includes a Wipe Memories button that:

  • Clears only the memories tagged with Source = "Chat" for that agent.
  • Does not affect other memories such as trial events or background information.
  • Useful for resetting the agent's conversation history without losing other context.
Important: The Wipe Memories action is irreversible. Only chat-sourced memories are removed; trial events and background memories are preserved.

Tips for Effective Chat

  • Be specific in your questions to get more relevant responses.
  • Use the agent's role as context — a judge will respond differently than a witness.
  • If an agent seems to forget context, check that their model is properly configured.
  • Use Wipe Memories if the agent's chat history becomes too long or irrelevant.
