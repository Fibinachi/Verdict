Model Configuration

Verdict supports multiple LLM (Large Language Model) providers for AI-powered features including agent chat, evidence analysis, and juror behavior simulation. Proper model configuration is essential for the application to function correctly.

Accessing Model Settings

  1. Click the Settings menu in the main menu bar.
  2. Select Model Settings from the dropdown menu.
  3. The ModelSettingsWindow opens, displaying all configured models and providers.

Note: The bias-factor weights and “model configuration” are shown in the same ModelSettingsWindow flow. The dedicated Model Weights dialog is opened from that window (via a button), but the overall configuration experience is on the same screen.

Supported Providers

Verdict includes providers for the following LLM services:

OpenAI Anthropic Google Gemini Ollama Hugging Face Alibaba NVIDIA Intel DeepSeek

Adding a Model

  1. In the Model Settings window, click the Add Model button.
  2. The AddModelDialog opens, prompting you to select a provider and configure model details.
  3. Enter the required information:
    • Provider — Select from the list of supported providers.
    • Model Name/ID — The specific model identifier (e.g., "gpt-4", "claude-3-opus-20240229").
    • API Key — Your API key for the provider (if required).
    • API Endpoint — The endpoint URL (may be pre-filled for standard providers).
    • Parameters — Optional settings like temperature, max tokens, etc.
  4. Click Save to add the model to your configuration.

Important: The “base weight” (bias-factor weights) settings are not part of the individual LLM model configuration stored in each AIModelConfiguration. They are adjusted separately via the dedicated Model Weights dialog (opened from the Model Settings screen), and are applied as the juror bias calibration inputs.

Testing a Connection

After adding a model, you can test the connection to verify it works:

  1. Select the model from the list in the Model Settings window.
  2. Click the Test Connection button.
  3. The application sends a test request to the provider and displays the result.
  4. A successful test confirms the model is ready for use.

Downloading Models

For local providers like Ollama, you can download models directly:

  1. Select the Ollama provider in the Model Settings window.
  2. Click the Download Models button to browse available models.
  3. Select a model to download and install locally.

Per-Agent Model Selection

Each agent can be assigned a specific model for its interactions:

  1. Open the Agent Profile Window for the agent (right-click > Edit Profile).
  2. In the profile settings, find the Model dropdown.
  3. Select the desired model from your configured models.
  4. Save the agent profile to apply the change.

This allows different agents to use different models based on their role and requirements. For example, you might assign a more powerful model to the Judge while using a lighter model for jurors.

Note: Some providers require API keys. Ensure you have valid credentials before testing or using a model. Local providers like Ollama do not require API keys.
