Courtroom Layout

The Verdict courtroom is organized into several distinct areas, each serving a specific function in the simulation.

Bench Area

The bench area is located at the front of the courtroom and contains three seats with Margin="12,0" spacing for visual separation:

  • Judge — Presides over the courtroom. Right-click for options including Chat and Edit Profile.
  • Reporter — Court reporter seat for recording proceedings.
  • Witness Box — Where witnesses are seated during testimony.

Counsel Tables

  • Prosecution / Plaintiff — Right-side table for the prosecution or plaintiff's legal team.
  • Defense — Left-side table for the defense legal team.

Each counsel table can hold multiple agents. Click + to add an attorney or party representative.

Jury Box

The jury box contains:

  • 12 Primary Seats — For the main jury panel.
  • 2 Alternate Seats — For alternate jurors who may replace primary jurors if needed.

Use the Generate Jury button to automatically populate the jury box with demographically-generated jurors. Each juror has unique demographics, biases, and personality traits that influence their decision-making.

Right-click any juror seat to access Juror Report for detailed sentiment and verdict lean analysis.

Observer Box

The observer box provides up to 6 seats for gallery observation:

  • 4 Observer Seats — For general observers or additional personnel.
  • 2 Client Slots — Reserved for the plaintiff and defendant clients.

Clerk Seat

Clerk — The clerk seat is highlighted in green and serves as the evidence submission point. You can:

  • Drag and drop document files onto the clerk seat to submit them as evidence.
  • Use the ADMIT EVIDENCE button to open a file dialog for document selection.

Interactive Points

  • Left-click "+" on any empty seat to add or activate an agent (opens Agent Profile window).
  • Right-click any occupied seat for a context menu with options: Edit Profile, Generate Likely Juror, Chat, Juror Report, Save as Character (.VCS), Save to Casefile, Delete.
  • Central Podium Button focuses the input prompt for text entry.
