Exhibit List

The Exhibit List provides a comprehensive view of all evidence submitted in the current case. It is accessible from the Case menu.

Opening the Exhibit List

  1. Click the Case menu in the main menu bar.
  2. Select _Exhibit List from the dropdown menu.
  3. The ExhibitListWindow opens, displaying all evidence in a table format.

Table Columns

The Exhibit List displays evidence in a ListView with the following columns:

Column Description
Exhibit # A sequential number assigned to each piece of evidence when submitted.
File Name The original filename of the submitted evidence document or image.
Summary A brief AI-generated summary of the evidence content.
Clerk Notes Any notes added by the clerk or user regarding the evidence.
Strength An AI-assessed strength rating indicating how compelling the evidence is.
Admitted A checkbox or indicator showing whether the evidence has been formally admitted into the case.

Using the Exhibit List

  • Review all submitted evidence in one centralized location.
  • Check the Strength column to identify the most compelling evidence for your arguments.
  • Use the Admitted status to track which evidence has been formally entered into the record.
  • Refer to exhibit numbers when referencing evidence during trial proceedings.
Tip: The Exhibit List is read-only for viewing. To add new evidence, use the ADMIT EVIDENCE button or drag files onto the Clerk seat in the main courtroom.
